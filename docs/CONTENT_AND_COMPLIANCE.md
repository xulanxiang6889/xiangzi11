# Content and Compliance

## 可销售或提供的内容

- 原创课程与教程
- 原创模板、提示词包与工作流清单
- 合法的软件教学与设计资源
- 资料库访问权益
- 咨询、评审与实施服务

## 不可销售或提供的内容

- 第三方账号、密码、Token、API key、2FA、Cookie 或会话
- 绕过认证、验证码、风控或访问控制的服务
- 未授权获取、出售或传输个人数据
- 侵犯版权、商标、隐私或商业秘密的材料
- 伪造评论、订单、用户数、品牌背书或安全声明

## 运营原则

所有示例数据均为 mock 且明确标示；不接真实支付、邮件、短信或第三方账号。用户提交的请求只在本地演示状态机中流转，生产接入必须另行获得人工批准并完成隐私、退款与支持流程审查。
