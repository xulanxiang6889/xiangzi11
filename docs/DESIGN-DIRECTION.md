# Design Direction

## 三个候选方向

### A · Quiet Cartography（推荐）

- 风格：安静制图、编辑型信息架构、冷青点缀。
- 适配理由：资源目录和教程需要可扫描的层级；几何 hero-mark 可自然延展为“路线/节点”视觉。
- 风险：过度克制可能显得冷，需要用真实中文内容和明确 CTA 增加温度。
- 版式：非对称 hero、宽留白、单列阅读流与 3 列资源网格交替。

### B · Material Workshop

- 风格：纸张、卡片、轻微材质叠层、工作台隐喻。
- 适配理由：适合模板、课程、咨询等“可拿走的工具”表达。
- 风险：卡片层叠容易滑向 SaaS 仪表盘模板。
- 版式：左侧内容叙事，右侧工具卡；章节使用细边框和状态标签。

### C · Monochrome Signal

- 风格：近黑白、强排版、极少青绿色信号。
- 适配理由：适合强调可信、专业与内容密度控制。
- 风险：对中文长文本的亲和力较弱，移动端可能显得沉重。
- 版式：大标题、短段落、横向分隔线与单一行动按钮。

## 评审结论

- `frontend-design` 推演后，A 最适合同时承载首页叙事、目录筛选和教程阅读。
- `design-taste-frontend` 评审：B 的卡片叠层最容易产生模板味，淘汰 B。
- `minimalist-ui` 评审：A 与 C 均保留足够留白；A 的内容节奏更适合新用户。
- `high-end-visual-design` 评审：A 通过细线、低对比阴影和几何标记建立质感，避免彩色光效。

## 推荐与备选

推荐：A · Quiet Cartography。备选：C · Monochrome Signal。

当前项目已有“冷青 + 深墨”和几何 hero-mark，继承其原创资产，不改组件结构。若切换到备选，只需修改 `src/styles/tokens.css` 的 semantic/component token 值与对应 `tokens.json`，不改路由、组件接口或内容结构。

## 硬性参数

- 桌面区块间距：96–120px；最大内容宽度：1180px。
- 字号阶梯：5 级；正文 16px，行高约 1.6。
- 色彩：1 个主色、1 个强调色和中性灰阶；主色面积低于 10%。
- 圆角：8px、16px、24px；阴影：无/柔和两级。
- 动效：140–220ms 的 transform/opacity；尊重 reduced-motion。
